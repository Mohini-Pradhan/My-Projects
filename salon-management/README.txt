Salon Management System

Requirements:
- XAMPP
- PHP
- MySQL

How to run:
1. Extract the project folder into:
   C:\xampp\htdocs\my_ws_php_classes\My-Projects\

2. Open XAMPP and start Apache and MySQL.

3. Open phpMyAdmin:
   http://localhost/phpmyadmin

4. Create/import the database:
   - Click Import
   - Select database.sql from the project folder
   - Click Go

5. Open the project in browser:
   http://localhost/my_ws_php_classes/My-Projects/salon-management/

6. Database Name: salon_db

7. Main Features:
    - Customer registration and login
    - Customer portal and appointment booking
    - Admin dashboard
    - Customer management
    - Service management
    - Beautician management
    - Appointment management
    - Payment and invoice management
    - Reports
    - Beautician leave management
